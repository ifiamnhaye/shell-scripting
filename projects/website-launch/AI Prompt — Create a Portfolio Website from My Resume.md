# AI Prompt — Create a Portfolio Website from My Resume

You are an experienced **UI/UX and web designer** with strong expertise in creating modern, professional, single-page portfolio websites.

I have attached my **resume/CV as the source file**. Read it carefully and use the information from my resume to build the portfolio website.

Do **not invent or assume** any professional experience, skills, certifications, education, projects, contact information, or achievements that are not present in my resume.

Create a modern, visually impressive **single-page portfolio website** based on my resume.

The website should include, where applicable:

- Hero section
- Professional summary / About Me
- Technical skills
- Work experience
- Projects
- Education
- Certifications
- Contact information
- GitHub and LinkedIn links, if available in the resume

### Design Requirements

Use a modern **glassmorphism UI** with:

- Beautiful glass-style cards
- Smooth hover animations
- Elegant transitions
- Subtle background effects
- Modern typography
- Professional spacing and visual hierarchy
- Smooth scrolling
- Responsive navigation
- Attractive icons
- Clean section transitions
- Fully responsive design for desktop, tablet, and mobile

Use the attached resume as the **primary source of content**, while improving only the presentation, organization, wording, and visual structure where appropriate.

Keep the website professional and suitable for **recruiters, hiring managers, and potential employers**.

The final result should feel **premium, modern, polished, and production-ready**, not like a basic HTML template.

Keep the code:

- Clean
- Well organized
- Properly commented
- Easy to maintain
- Responsive
- Accessible
- Free from broken links or sections

### Important

Do not add fake information.

If any information needed for a section is missing from the resume, either omit that section or leave it minimal instead of inventing content.

### Goal

Create one of the best-looking professional portfolio websites possible using the information from my attached resume.
